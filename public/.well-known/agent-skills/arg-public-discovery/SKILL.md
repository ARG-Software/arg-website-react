# ARG Software Public Discovery

Use this skill when an agent needs to understand ARG Software's public services, project portfolio, articles, and contact paths.

- Blog: https://arg.software/blog/

- Sitemap: https://arg.software/sitemap.xml
- Contact: https://arg.software/contact/

## Recommended Flow

1. Read `llms.txt` for a compact overview.
2. Read `llms-full.txt` when more detail is needed.
3. Use the sitemap or feeds to discover current public pages and articles.
4. Use the read-only MCP endpoint at `https://arg.software/mcp` for structured public company, service, project, blog, and contact metadata.
5. Send humans to `https://arg.software/contact/` or `hello@arg.software` for project discussions.

## Boundaries

Do not claim ARG provides self-service OAuth credentials or agent registration. ARG currently handles partner and agent integration requests manually through `hello@arg.software`.
